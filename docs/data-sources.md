# 商品资料来源

2026年11月9日版包含132件精选商品：100条MUJI官方商店文具资料、29条真实书目和3件原创样例。升级时还会保留已进入旧购物袋的早期样例，因此本机在售数量可能高于132。历史订单不会被改写。

## 新增真实商店目录

100条文具资料来自 [MUJI美国官方文具目录](https://www.muji.us/collections/stationery)，通过该站公开商品目录读取品名、SKU、规格选项、美元价格及图片，没有使用登录账号或绕过访问限制。296张商品图随应用保存。中文导读名称及场景介绍由本项目整理，没有整段复制营销文案。

`data/merchant-catalog.json`逐项保存来源页面、原始品名、来源SKU、货币、原站价格、采集时间、规格选项及原始图片URL。来源价格是美元快照，本站人民币价格与库存为独立的演示设置，不代表实时汇率、商家报价或销售承诺；本项目不是MUJI官方商城。

导入程序为`scripts/import_merchant_catalog.py`，默认仅生成资料快照。生成SQL必须指定未使用的`--migration-version`，不会覆盖已有迁移。V11扩展多图、规格与来源价格字段，V12保存本次验收快照。旧样例中未进入购物袋的商品已下架；旧购物袋内商品维持原价与可售状态，供用户继续下单，后续可由管理员手动下架。

## 原创文创

笔记本、帆布袋和书签为原创演示商品，图形由 Codex 辅助绘制。商品规格、价格和库存为虚构样例。

## 历史公开电商原型目录

75条商品名称、品牌和商品图来自 [DummyJSON 商品接口](https://dummyjson.com/docs/products)。来源提供的是用于测试及原型的样例目录，不能将这些记录称为从真实零售商抓取的在售库存。图片保存在前端目录，避免应用运行时依赖该接口。本站人民币价格是演示换算值，库存由导入脚本产生，不代表品牌或商家报价。

## 真实书目

29条在售书目的书名、作者、首次出版年份及链接来自 [Open Library Search API](https://openlibrary.org/dev/docs/api/search)。初版曾按其展示建议引用外部封面，浏览器实测发现部分图片加载不稳定，因此最终页面使用本站原创书目示意封面，明确说明不是出版社实物封面。原始封面URL保存在来源记录中，没有批量抓取外部封面。本站价格与库存为演示值，不对应实际销售版本。

## 可追溯记录

`data/catalog.json` 保存导入时间和每件商品的来源类型及来源地址。`scripts/import_catalog.py` 为可重现的导入脚本，缓存原始响应，图片下载失败的记录不会写入最终目录。Flyway V4 迁移保存已验收的导入快照；后续增加数据应创建新迁移，不能修改已经执行过的历史迁移。

V6整理中文商品名并保留原始名称；V9进一步整理书目，补充《傲慢与偏见》《小王子》《时间简史》的真实元数据。中文名用于阅读导览，不声称对应中文出版版本或官方商品译名。

V10切换到本地原创书目示意封面，生成脚本为 `scripts/generate_book_covers.py`。所有在售商品图均随应用保存，商品展示不依赖外部图片服务。

本项目是课程演示商城；保留来源说明不代表获得相关品牌背书。首次导入使用公开接口和元数据，不声称模拟商品是实际在售商品。
